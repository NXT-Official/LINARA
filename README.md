# Linara

**Home, made clear.** Linara is a calm, shared home-management app for Filipino households —
it coordinates family members (primary manager, co-manager, remote admin/OFW) and household
helpers (yaya, cook, driver, laundry, all-around) around one shared daily board.

The current codebase is a front-end-only prototype: all state lives in React memory, there is
no database, auth, or network call, and a refresh resets everything.

## Tech stack

| Layer     | Choice                                                           |
| --------- | ---------------------------------------------------------------- |
| Framework | TanStack Start v1 (SSR) on Vite 8                                |
| Routing   | TanStack Router v1, file-based, generated route tree             |
| Data      | TanStack Query v5 (client wired up; no queries defined yet)      |
| UI        | React 19, TypeScript 5.8 strict, Tailwind CSS v4, Radix / shadcn |
| Server    | Nitro v3 (SSR/edge output under `.output/`)                      |
| Tooling   | Bun, ESLint 9 flat config, Prettier                              |

## Requirements

- [Bun](https://bun.sh) 1.1+ (package manager and script runner)
- Node.js 20+ if you want to run the built server with `node`

## Installation

```bash
bun install
```

## Environment setup

The app reads no environment variables today. When that changes, copy the template and fill
it in:

```bash
cp .env.example .env
```

`VITE_`-prefixed variables are exposed to the browser bundle; everything else stays
server-side. `.env` files are gitignored — never commit real values.

## Deployment notes

`bun run build` produces a Nitro server bundle in `.output/`, runnable anywhere Node or Bun
is available:

```bash
node .output/server/index.mjs   # PORT=3000 by default
```

For a specific platform (Cloudflare Workers, Vercel, Netlify, …), set the matching Nitro
preset via the `nitro()` plugin options in `vite.config.ts` or the `NITRO_PRESET` environment
variable, then rebuild. No platform-specific configuration is committed today.
